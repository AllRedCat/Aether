## 3. Initialization Lifecycle & Environment Setup

### 3.1 App Initialization Sequence (`main.dart`)
FRB requires initializing the native bindings before invoking any FFI endpoints. The initialization flow consists of two sequential phases:

```dart
void main() async {
  // 1. Ensure Flutter engine bindings are initialized
  WidgetsFlutterBinding.ensureInitialized();

  // 2. Initialize flutter_rust_bridge native library loader
  await RustLib.init();

  // 3. Initialize Aether native subsystems (Render, Media, Logger)
  await initEngine();

  // 4. Launch Flutter widget tree wrapped with Riverpod ProviderScope
  runApp(const ProviderScope(child: AetherApp()));
}
```

#### Behavior & Diagnostics:
- `RustLib.init()` loads `libaether_bridge.dylib` (configured relative path: `../../crates/aether_bridge/target/release/` or system bundle).
- If `RustLib.init()` is omitted or fails, invoking `initEngine()`, `createTimeline()`, or `addClipToTrack()` will throw a `StateError` / `FrbException`: `"RustLib has not been initialized"`.
- `initEngine()` calls `crates/aether_bridge/src/api.rs::init_engine()`, which executes:
  - `flutter_rust_bridge::setup_default_user_utils()`
  - `aether_render::init_render()`
  - `aether_media::init_media()`

### 3.2 Testing Lifecycle & Mocking (`RustLib.initMock`)
In Flutter unit and widget tests where native dynamic libraries (`.dylib` / `.so`) are not compiled or loaded, FRB provides a mock hook:

```dart
class MockRustLibApi extends Mock implements RustLibApi {}

void main() {
  setUpAll(() {
    RustLib.initMock(api: mockRustLibApi);
  });
}
```
Furthermore, because `Timeline`, `Track`, `Clip`, and `Rational` are pure Dart classes with public `const` constructors, unit tests can instantiate concrete data structures directly in Dart without touching FFI at all (as verified in `test/bridge_contract_test.dart`).

## 4. FFI Function Signatures, Parameters, & Error Handling

### 4.1 `initEngine()`
- **Dart Signature**:
  ```dart
  Future<void> initEngine();
  ```
- **Parameters**: None.
- **Return Type**: `Future<void>`
- **Native Implementation**: `aether_bridge::api::init_engine()`
- **Exceptions**: Throws `FrbException` if FFI bridge is uninitialized; throws `PanicException` if native rendering/media initialization panics.

---

### 4.2 `createTimeline()`
- **Dart Signature**:
  ```dart
  Future<Timeline> createTimeline();
  ```
- **Parameters**: None.
- **Return Type**: `Future<Timeline>`
- **Native Behavior**:
  ```rust
  pub fn create_timeline() -> Timeline {
      let mut timeline = Timeline::new(Rational { num: 60, den: 1 });
      timeline.add_track(TrackKind::Video);
      timeline
  }
  ```
  Returns a `Timeline` with:
  - `id`: Unique v4 `UuidValue`
  - `timebase`: `Rational(num: 60, den: 1)` (60 fps)
  - `durationPts`: `0`
  - `tracks`: A `List<Track>` containing 1 default `TrackKind.video` track with `clips: []`.
- **Exceptions**: Can throw `FrbException` or `PanicException`. Rust side does not return `Result`, so no domain errors are produced.

---

### 4.3 `addTrack({required Timeline timeline, required TrackKind kind})`
- **Dart Signature**:
  ```dart
  Future<Timeline> addTrack({
    required Timeline timeline,
    required TrackKind kind,
  });
  ```
- **Parameters**:
  - `timeline`: Existing `Timeline` instance.
  - `kind`: `TrackKind` enum (`TrackKind.video`, `TrackKind.audio`, `TrackKind.overlay`).
- **Return Type**: `Future<Timeline>` (updated timeline with new empty track appended).

---

### 4.4 `addClipToTrack(...)`
- **Dart Signature**:
  ```dart
  Future<Timeline> addClipToTrack({
    required Timeline timeline,
    required UuidValue trackId,
    required UuidValue sourceId,
    required int sourceIn,
    required int sourceOut,
    required int timelineIn,
  });
  ```
- **Parameters**:
  | Parameter | Dart Type | Rust Type | Description & Invariant Rules |
  |---|---|---|---|
  | `timeline` | `Timeline` | `Timeline` | Current immutable timeline snapshot |
  | `trackId` | `UuidValue` | `Uuid` | Target track ID. Must exist in `timeline.tracks` |
  | `sourceId` | `UuidValue` | `Uuid` | Media asset source ID |
  | `sourceIn` | `int` | `i64` | In-point on source asset (must be `>= 0` and `<= sourceOut`) |
  | `sourceOut` | `int` | `i64` | Out-point on source asset (must be `>= sourceIn` and `>= 0`) |
  | `timelineIn` | `int` | `i64` | In-point offset on timeline (must be `>= 0`) |

- **Return Type**: `Future<Timeline>`
  Returns the updated `Timeline` with the new clip appended to the specified track and `timeline.durationPts` recalculated:
  `clip.timelineOut = timelineIn + (sourceOut - sourceIn)`
  `timeline.durationPts = max(all clip.timelineOut across all tracks, 0)`

- **Exception & Error Propagation**:
  In Rust, `add_clip_to_track` returns `Result<Timeline, String>`:
  ```rust
  timeline.add_clip(track_id, clip).map_err(|e| e.to_string())?;
  ```
  FRB uses `SseCodec(decodeSuccessData: sse_decode_timeline, decodeErrorData: sse_decode_String)`.
  When Rust returns `Err(message)`, the SSE decoder throws the `String` directly in Dart!

  **Specific Error Messages Thrown by Rust Domain:**
  1. **Track Not Found**:
     `"Track with ID <uuid> not found"`
     (Triggered when `trackId` is not present in `timeline.tracks`)
  2. **Invalid Source Bounds**:
     `"Invalid source bounds: source_in (<in>) > source_out (<out>)"`
     (Triggered when `sourceIn > sourceOut` or `sourceIn < 0` or `sourceOut < 0`)
  3. **Invalid Clip Timeline Bounds**:
     `"Invalid clip timeline bounds: timeline_in (<in>) > timeline_out (<out>)"`
     (Triggered when `timelineIn < 0`)

- **Dart Error Handling Pattern**:
  ```dart
  try {
    final updatedTimeline = await addClipToTrack(
      timeline: state.timeline!,
      trackId: targetTrackId,
      sourceId: sourceId,
      sourceIn: sourceIn,
      sourceOut: sourceOut,
      timelineIn: timelineIn,
    );
    // Success: update state
  } catch (error, stackTrace) {
    // error is String or FrbException
    final String message = error.toString();
    // Handle or display error in UI
  }
  ```

## 5. UUID Representation & Instantiation in Dart

The `uuid` package (`version ^4.4.0`) is used throughout the Dart bridge.

### 5.1 Type Mapping
- Rust `uuid::Uuid` $\leftrightarrow$ Dart `UuidValue` (from `package:uuid/uuid.dart`).
- All IDs on `Timeline.id`, `Track.id`, `Clip.id`, and `Clip.sourceId` are `UuidValue`.

### 5.2 How to Instantiate `UuidValue` in Dart
```dart
import 'package:uuid/uuid.dart';

// 1. Generate a new random UUID v4 as UuidValue:
final UuidValue newId = const Uuid().v4obj();

// 2. Parse from a known UUID String without validation:
final UuidValue parsedId = UuidValue.fromString('a0000000-0000-0000-0000-000000000001');

// 3. Parse with strict RFC 9562 validation:
final UuidValue strictId = UuidValue.withValidation('a0000000-0000-0000-0000-000000000001');

// 4. Convert UuidValue back to String:
final String uuidStr = newId.uuid; // or newId.toString()

// 5. Value equality:
expect(
  UuidValue.fromString('a0000000-0000-0000-0000-000000000001'),
  equals(UuidValue.fromString('a0000000-0000-0000-0000-000000000001')),
); // true
```

### 6.2 Key Operational Patterns

1. **64-bit Integer Precision**:
   Because `make bridge` was run with `--type-64bit-int`, all timestamps (`sourceIn`, `sourceOut`, `timelineIn`, `timelineOut`, `durationPts`) are native Dart `int` primitives. No `BigInt`, `Int64`, or manual casting is needed.

2. **Accessing Tracks and Clips**:
   - `timeline.tracks`: Direct `List<Track>`.
   - `track.clips`: Direct `List<Clip>`.
   - Iterate over clips:
     ```dart
     for (final track in timeline.tracks) {
       for (final clip in track.clips) {
         print('Clip: ${clip.id.uuid} [${clip.timelineIn}..${clip.timelineOut}]');
       }
     }
     ```

3. **Total Clip Count Calculation**:
   ```dart
   final int totalClipCount = timeline.tracks.fold<int>(
     0,
     (acc, track) => acc + track.clips.length,
   );
   ```

4. **Finding Target Track**:
   ```dart
   // First video track:
   final Track videoTrack = timeline.tracks.firstWhere(
     (t) => t.kind == TrackKind.video,
     orElse: () => timeline.tracks.first,
   );
   final UuidValue targetTrackId = videoTrack.id;
   ```

5. **Equality Note**:
   `Clip` and `Rational` have deep value equality. `Track` and `Timeline` perform `==` on their list fields (`tracks == other.tracks`). In Dart, two distinct `List` instances are not `==` by reference. Therefore, Riverpod state should always be updated with new state objects.

### 7.1 `timeline_provider.dart`
Path: `apps/aether_app/lib/src/features/timeline/timeline_provider.dart`

```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:uuid/uuid.dart';
import '../../bridge/api.dart';

/// State representation for the Timeline feature in Aether.
class TimelineState {
  final Timeline? timeline;
  final int totalClipCount;
  final int durationPts;
  final List<Track> tracks;
  final bool isLoading;
  final String? errorMessage;

  const TimelineState({
    this.timeline,
    this.totalClipCount = 0,
    this.durationPts = 0,
    this.tracks = const [],
    this.isLoading = false,
    this.errorMessage,
  });

  const TimelineState.initial()
      : timeline = null,
        totalClipCount = 0,
        durationPts = 0,
        tracks = const [],
        isLoading = false,
        errorMessage = null;

  factory TimelineState.fromTimeline(Timeline timeline, {bool isLoading = false}) {
    final count = timeline.tracks.fold<int>(
      0,
      (acc, track) => acc + track.clips.length,
    );
    return TimelineState(
      timeline: timeline,
      totalClipCount: count,
      durationPts: timeline.durationPts,
      tracks: timeline.tracks,
      isLoading: isLoading,
      errorMessage: null,
    );
  }

  TimelineState copyWith({
    Timeline? timeline,
    int? totalClipCount,
    int? durationPts,
    List<Track>? tracks,
    bool? isLoading,
    String? errorMessage,
    bool clearError = false,
  }) {
    return TimelineState(
      timeline: timeline ?? this.timeline,
      totalClipCount: totalClipCount ?? this.totalClipCount,
      durationPts: durationPts ?? this.durationPts,
      tracks: tracks ?? this.tracks,
      isLoading: isLoading ?? this.isLoading,
      errorMessage: clearError ? null : (errorMessage ?? this.errorMessage),
    );
  }
}

/// StateNotifier that coordinates Timeline operations with the native Rust core via FFI.
class TimelineNotifier extends StateNotifier<TimelineState> {
  final Uuid _uuid = const Uuid();

  TimelineNotifier() : super(const TimelineState.initial()) {
    initTimeline();
  }

  /// Initializes the default timeline from Rust core via createTimeline().
  Future<void> initTimeline() async {
    state = state.copyWith(isLoading: true, clearError: true);
    try {
      final timeline = await createTimeline();
      state = TimelineState.fromTimeline(timeline);
    } catch (e) {
      state = state.copyWith(
        isLoading: false,
        errorMessage: 'Failed to initialize timeline: $e',
      );
    }
  }

  /// Appends a new clip to the target track in the timeline.
  /// If trackId is omitted, it defaults to the first available track.
  Future<void> addClip({
    UuidValue? trackId,
    UuidValue? sourceId,
    int sourceIn = 0,
    int sourceOut = 60,
    int? timelineIn,
  }) async {
    final currentTimeline = state.timeline;
    if (currentTimeline == null || currentTimeline.tracks.isEmpty) {
      state = state.copyWith(errorMessage: 'No active timeline or track available');
      return;
    }

    if (state.isLoading) return; // Prevent concurrent re-entrant calls

    final targetTrack = trackId != null
        ? currentTimeline.tracks.firstWhere(
            (t) => t.id == trackId,
            orElse: () => currentTimeline.tracks.first,
          )
        : currentTimeline.tracks.first;

    final targetSourceId = sourceId ?? _uuid.v4obj();
    // Default insertion point is at the current end of the timeline
    final insertionPts = timelineIn ?? currentTimeline.durationPts;

    state = state.copyWith(isLoading: true, clearError: true);

    try {
      final updatedTimeline = await addClipToTrack(
        timeline: currentTimeline,
        trackId: targetTrack.id,
        sourceId: targetSourceId,
        sourceIn: sourceIn,
        sourceOut: sourceOut,
        timelineIn: insertionPts,
      );

      state = TimelineState.fromTimeline(updatedTimeline);
    } catch (e) {
      state = state.copyWith(
        isLoading: false,
        errorMessage: 'Failed to add clip: $e',
      );
    }
  }
}

/// Riverpod Provider exposing the TimelineNotifier and its TimelineState.
final timelineProvider =
    StateNotifierProvider<TimelineNotifier, TimelineState>((ref) {
  return TimelineNotifier();
});
```

## 8. Verification Matrix & Edge Case Checklist

| Scenario | Input / Action | Expected Engine / State Behavior |
|---|---|---|
| **App Startup** | `RustLib.init()` then `initEngine()` | Native library loaded, engine subsystems initialized without exception |
| **Initial Timeline** | `createTimeline()` | Returns `Timeline` with 1 Video track, 0 clips, `durationPts: 0` |
| **Default Add Clip** | `addClip()` without parameters | Clip added to Track 1; `timelineIn = current durationPts`; `durationPts` increased by 60; `totalClipCount` incremented |
| **Concurrent Taps** | Rapid double tap on `add_clip_button` | Debounced via `isLoading` check; button disabled during flight |
| **Invalid Track ID** | Non-existent `UuidValue` passed to `addClipToTrack` | Rust returns `Err("Track with ID ... not found")`; caught and stored in `state.errorMessage` |
| **Negative Bounds** | `sourceIn < 0` or `timelineIn < 0` | Rust returns `Err("Invalid source/clip bounds")`; caught and stored in `state.errorMessage` |
| **Reversed Bounds** | `sourceIn > sourceOut` | Rust returns `Err("Invalid source bounds")`; UI shows error banner |
| **Direct Field Access** | `timeline.tracks[0].clips[0].timelineIn` | Unboxed native `int` without BigInt or dynamic conversion |
